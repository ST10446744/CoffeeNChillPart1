# CoffeeNChill Part 1 - Postman Collection

The Postman collection included in this project contains all required Part 1 HTTP endpoints.

## Collection

CoffeeNChill-Part1.postman_collection.json

## Endpoints Included

- Create Menu Item
- Get All Menu Items
- Get Menu Items By Category
- Update Menu Item
- Delete Menu Item
- Upload Staff Document
- List Staff Documents
- Download Staff Document

## Base URL

http://localhost:7071

The collection was used to verify the CoffeeNChill Functions application locally and while running in Docker.
